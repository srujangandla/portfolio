Telecom ML & Telemetry

Network Service Availability Prediction

Machine learning framework for retrospective anomaly classification on 32,000 multi-dimensional telecom radio access network KPI time series.

What I built: Feature extraction pipeline engineering 110 physical-layer KPI statistics (RSRP, UL_SNR, UL_BLER) and class-weighted Random Forest model.

Result: F1 = 0.9577, Precision = 1.0000, False Alarm Rate = 0.0000, Recall = 0.9189 on 32,000 trace windows (File: readme.md)

Epidemiological ML

Disease Outbreak Prediction and Surge Analysis

Predictive modeling pipeline in R analyzing 8,970 Indian district outbreak reports with climate telemetry to identify case surge drivers.

What I built: End-to-end R analytics pipeline, leakage-free temporal validation splits (train 2009–2017, test 2018–2019, stress 2020–2022), Random Forest regression, and Logistic surge classifier.

Result: Random Forest RMSE = 0.95 (R² = 0.18 vs 0.00 baseline); Logistic surge PR-AUC = 0.44 vs 0.22 baseline (File: README.md)
